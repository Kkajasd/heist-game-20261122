The Gilded Hour — a top-down heist game for the best-heist-game-20261122-0559 bounty on make.fun. Cross the Meridian Museum after hours, read the guards' vision cones, mind the sweeping cameras, steal the golden pocket watch from its pedestal, and slip out the door before the alarm hits lockdown. Smoke pellets and tossed coins buy you room; sprinting is fast and loud.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play with WASD or the arrow keys (Shift to sprint, Q to toss a coin, E for a smoke pellet, P to pause).
